# MAD-ADL1-Study
Source Repository for MAD ADL1 loss study

## Overview of the work

Medical image deblurring requires preserving anatomical structures whose diagnostic significance derives from second-order geometric properties such as trabecular bone curvature, vessel bifurcation geometry, and tissue interface sharpness. This work establishes, through functional analysis in Sobolev spaces, that loss functions controlling only the $W^{1,1}$ norm cannot bound Laplacian errors, providing formal proof that explicit second-order supervision is mathematically necessary for curvature-preserving restoration. 

We introduce the Moving-Average-Division Augmented Differential $L_1$ (MAD-ADL$_1$) loss, which combines intensity, gradient, Laplacian, and frequency components with moving average normalization and bounded uncertainty weighting. The bounded uncertainty parameters, constrained to modality-specific intervals, prevent the optimizer from abandoning difficult geometric constraints. The framework is proved well-posed in the energy space $V(\Omega)$, with existence, uniqueness, and a quantitative convergence guarantee. The Analytic Continuity Gated U-Net (ACG-UNet) implements explicit geometric computation through Laplacian-gated skip connections and rational function fusion. The Spatially-Adaptive Gated Activation with a smooth softplus base ($\mathrm{SAGA}_\beta$) provides the $C^\infty$ regularity required for stable optimization under Laplacian supervision, with spatial gating that prevents the gradient diffusion exhibited by globally smooth activations.

The framework is validated through a three-phase experimental design on bone radiography and chest CT, followed by a blinded multi-reader clinical evaluation. Structural Similarity Index Measure (SSIM) loss fails on both modalities; Mean Absolute Error (MAE) achieves roughly half the edge preservation of MAD-ADL$_1$; $\mathrm{SAGA}_\beta$ outperforms Rectified Linear Unit (ReLU) by margins that scale with the Laplacian magnitude of the target modality; and the framework transfers to three architectures with no role in its development, with Enhanced Deep Residual Networks for Single Image Super-Resolution (EDSR) trained under MAD-ADL$_1$ and $\mathrm{SAGA}_\beta$ achieving the best performance observed in this study (46.57 dB PSNR, 0.946 SSIM on bone). The benefit of the framework scales consistently with the Laplacian magnitude of the target modality across independent loss-level and activation-level experiments.
